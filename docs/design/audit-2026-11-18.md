## Confirmed probes

### Reversed `diff` arguments

A valid additive change was compared in reverse:

```text
witforge diff v0.2 v0.1
old: … (example:t 0.2.0)
new: … (example:t 0.1.0)
removed  record field  types/r.b  number=2  wire:BREAKING source:BREAKING api:BREAKING
```

Forward, the field was an added defaultable field. A reversed `diff --check` would fail where the
forward comparison passes. `W10-026` fixes this.

### Root and direct order handling

The same tree with a stale order fingerprint produced:

```text
# direct endpoints
reordered  record field order  types/r  wire:compatible source:BREAKING api:compatible
result: BREAKING

# WIT roots
witforge: … declaration order of `example:t/types/r` changed …
exit 1
```

Direct loading is deliberately lenient so it can report a reorder; root loading uses the
generator-grade validation and refuses a stale lock. The documentation currently claims they
agree. `W10-026` records and tests the real boundary.

### Missing lock on a direct endpoint

```text
witforge diff old/v0.1 new/v0.2
witforge: … no v<major>.<minor> version directories under …/old/v0.1
```

`check` gives the actionable missing-lock remedy. `W10-026` mirrors it for `diff`.

### Released-directory symlinked lockfile

A released version directory with `wire.lock` replaced by a symlink passed `witforge check`
(exit `0`). `ci/check-release-freeze.sh` catches tracked symlinks in CI, but the standalone tool
does not enforce the boundary. `W10-029` closes the tool-level gap.

### Required addition blocks conversion generation

```text
diff --json: added  types/r.required  defaulted=false; conversion_impacts=[]
rust: types/r.required is required in 0.2.0 but absent from 0.1.0; … generation refused
```

`diff` does not say that conversion generation will refuse. `W10-036` adds the reporting.

### Fuzz workspace

`cargo fuzz build` emits:

```text
warning: binary `wit_package` should have a kebab-case name
```

`fuzz/` is also absent from Dependabot, the security scan, and the stable CI checks.
`W10-030` integrates it.
