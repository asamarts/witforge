## Why

Standard `protoc --python_out` messages accept out-of-range narrow integers, missing required optional scalars, unknown enum numbers, and unset oneofs silently. Checked Python protobuf glue targeting official `google.protobuf` enforces the exact WIT decode profile with structured `WitforgeGlueError` exceptions.

## Acceptance criteria

- [ ] Implement opt-in Python checked protobuf glue targeting official `google.protobuf` (`HasField` presence checks, `json_format` compatibility, per-function request/response helpers, `METHOD` constants, structured `WitforgeGlueError`)
- [ ] Enforce all 13 rows of the WIT decode profile for both binary protobuf and proto3-JSON payloads
- [ ] Add golden tests and cross-language round-trip conformance tests validating every valid and invalid `W11-034` fixture vector
