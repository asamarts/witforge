## Why

Golden tests prove expected cases; an adversarial pass finds the cases the
mapping table forgot, especially presence, unknown oneofs, and naming collisions.

## Acceptance criteria

- [x] malformed/absent required fields are rejected
- [x] unknown enum values and oneof cases are errors
- [x] required vs option presence is distinguished through glue
- [x] output is byte-identical across repeated runs
- [x] findings are fixed or filed as tasks with reproduction cases
