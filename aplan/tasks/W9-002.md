## Why

Native Rust consumers commonly need JSON/fixture serialization, but unconditional Serde
derives would impose a dependency and change every generated API.

## Acceptance criteria

- [ ] `[project.<name>.rust] serde = true` opts in, with a CLI override
- [ ] generated records, enums, variants, flags, and aliases derive Serialize/Deserialize correctly
- [ ] floats and nested wrappers are covered by compile/round-trip tests
- [ ] default output and existing generated APIs remain unchanged
- [ ] the generated code documents the consumer-provided serde dependency
