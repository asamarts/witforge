## Why

Native Rust consumers commonly need JSON/fixture serialization, but unconditional Serde
derives would impose a dependency and change every generated API.

## Acceptance criteria

- [x] `[project.<name>.rust] serde = true` opts in, with a CLI override
- [x] generated records, enums, variants, flags, and aliases derive Serialize/Deserialize correctly
- [x] floats and nested wrappers are covered by compile/round-trip tests
- [x] default output and existing generated APIs remain unchanged
- [x] the generated code documents the consumer-provided serde dependency
