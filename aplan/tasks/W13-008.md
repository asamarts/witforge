## Why

Java has the weakest upstream WIT ecosystem among major languages despite Java 21 LTS providing first-class `record` and `sealed interface` exhaustive pattern matching that fit WIT's algebraic model cleanly. Adding `witforge java` and checked `com.google.protobuf` glue brings full WIT-first contract compilation to JVM teams.

## Acceptance criteria

- [ ] Implement `witforge::emit::java` and `witforge java` CLI / `[project.<name>.java]` config emitting Java 21 LTS+ stdlib-only packages (`record`, `sealed interface ... permits ...`, `enum`, `Optional`, immutable defensive copies where appropriate, interfaces, `worlds`, `deps/`, Javadoc, `@Deprecated`)
- [ ] Implement opt-in Java checked protobuf glue targeting `com.google.protobuf` (`protobuf-java` + `protobuf-java-util` `JsonFormat`, paired with `W11-039`'s `java_package` / `java_multiple_files` options) enforcing all 13 decode-profile rules with structured `WitforgeGlueException`
- [ ] Add golden tests, deterministic `--check` tests, and `javac` / cross-language conformance tests against `W11-034` fixtures
