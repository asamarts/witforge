## Why

Java has the weakest upstream WIT ecosystem among major languages despite Java 21 LTS providing first-class `record` and `sealed interface` exhaustive pattern matching that fit WIT's algebraic model cleanly. Adding `witforge java` brings idiomatic, zero-dependency plain JVM contract models directly from WIT.

## Acceptance criteria

- [ ] Implement additive `witforge::emit::java` (`#[non_exhaustive]` `JavaOptions`, no `Copy`), `witforge java` CLI, and `[project.<name>.java]` config wired into `ensure_distinct_output_roots` and `witforge generate`, emitting Java 21 LTS+ stdlib-only nested package trees (`record`, `sealed interface ... permits ...`, `enum`, `Optional`, immutable defensive copies for collections/byte arrays, interfaces, `worlds`, `deps/` with `DepLayout`, Javadoc, `@Deprecated`)
- [ ] Enforce deterministic LF-only nested package directory trees via `output.rs`, ownership headers, keyword escaping, and `--check` drift detection
- [ ] Add offline golden/unit tests in `cargo test --workspace --locked`, update `docs/design/public-api-inventory.txt`, and document CLI/config keys in `docs/guide/reference.md`
