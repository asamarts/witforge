## Why

Audit findings E3, F3, F4, and F7.

Release state (re-run 2026-11-18): `ROADMAP.md:122-134` lists required-addition blockers,
reversed-endpoint rejection, missing-lock guidance, atomic generated writes, and symlink
refusal in released directories under "0.5.0 … (released)". None is in tag `v0.5.0`
(`git show v0.5.0:crates/witforge/src/lib.rs` has no `ensure_no_symlinks`; the tag's
`emit/output.rs` has no `write_atomic`). 51 commits on `main` are unreleased, and
`CHANGELOG.md` [Unreleased] omits three user-visible changes: atomic writes, the exit-2
refusal of symlinks inside released directories, and the Action's 30-second timeouts.
`diagnostics.md`, `diff.md`, `lockfile.md:41-44`, and `action.md:47-49` describe `main` while
the README tells users to install 0.5.0.

Stale or contradictory statements:

- `AGENTS.md:3-16` describes "the 0.1 line" with five commands and three specifications; it
  omits `schema`, `diff`, `--format`, `witforge.toml`, dependencies, Serde, `convert.rs`, and
  `diff.md`, `diagnostics.md`, `dependencies.md`, `action.md`.
- `AGENTS.md:77` gives `cargo test --workspace --locked` although the tests use
  `std::env::temp_dir()` and the same file forbids `/tmp`; only `ci/README.md` mentions
  `TMPDIR`.
- `emitters.md:36` says the generators "use distinct ownership headers"; Rust, proto, and
  glue share one (see `W10-073`).
- `lockfile.md:62,106` and `emitters.md:678` list commands without `schema`/`diff`;
  `emitters.md:651-653` omits `--serde`/`--no-serde`.
- `overview.md` section 5.2 says "numbers are never reused"; `lockfile.md` section 6 lets a
  dropped draft's number be reused.
- `lockfile.md` section 16 refers to parents "exactly as in section 5"; they are defined in
  section 3.
- `model.md:285` defers typed errors "before 1.0"; `public-api.md:52` says they are not
  promised for 1.0.
- `conformance.md` has no JSON Schema mapping row although `fixtures/emit/json` exists.
- `emitters.md` 3.7 and 5.2 say `witforge_deps.rs` is emitted when the package references a
  dependency; it is emitted whenever `deps/` is non-empty (dependencies.md agrees with the
  code).
- `emitters.md` 9.1 says `#[non_exhaustive]` protects exhaustive matches on
  `ConversionError`; it has no effect inside the crate that includes the generated module.
- `emitters.md` 3.1 shows a wrapped trait signature the emitter never produces.
- `crates/witforge/src/lib.rs:45` and `overview.md:3-6` name only rust/proto/glue.
- `docs/design/audit-2026-11-18.md` states that no remediation work remains.
