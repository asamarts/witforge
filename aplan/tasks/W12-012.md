## Why

Only `site/astro.config.mjs` and `site/scripts/check-links.mjs` previously opted into TypeScript checking via `// @ts-check`, leaving `markdown-utils.mjs`, `sync-docs.mjs`, `emit-redirects.mjs`, and `test-scripts.mjs` unchecked and widening imported helpers to `any`. Enabling `// @ts-check` across every script in `site/scripts/` and running `tsc --noEmit` inside `npm --prefix site run check` closes that type-safety gap in local verification and CI.

## Why it is untestable

This task modifies Node helper scripts and npm configuration under `site/` rather than Rust crate code under `crates/**` covered by `.aplan.yml`'s Cargo test runners. Its invariants are verified by `node --test site/scripts/test-scripts.mjs` (21 tests, also invoked by `cargo test -p witforge-cli --test tooling --locked`), `npm --prefix site run check` (`astro check && tsc --noEmit`), and `.github/workflows/docs.yml`.

## Acceptance criteria

- [x] Every `.mjs` module in `site/scripts/` starts with `// @ts-check` and declares accurate JSDoc types
- [x] `npm --prefix site run check` runs `tsc --noEmit` alongside `astro check` with zero errors or warnings
- [x] `site/scripts/test-scripts.mjs` asserts that every `site/scripts/*.mjs` module carries `// @ts-check`
- [x] `npm --prefix site run verify` and `cargo test -p witforge-cli --test tooling --locked` pass cleanly

## What was done

- Added `// @ts-check` and full JSDoc parameter, return, and `@typedef` annotations to `site/scripts/markdown-utils.mjs`, `site/scripts/sync-docs.mjs`, `site/scripts/emit-redirects.mjs`, and `site/scripts/test-scripts.mjs`.
- Added a regression unit test in `site/scripts/test-scripts.mjs` verifying that every `.mjs` file under `site/scripts/` starts with `// @ts-check` (21/21 unit tests passing).
- Updated `site/package.json`'s `"check"` script to run `node scripts/sync-docs.mjs && astro check && tsc --noEmit`, ensuring `npm --prefix site run verify` and `.github/workflows/docs.yml` enforce full TypeScript 6.0 checking end-to-end.
