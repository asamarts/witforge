## Why

`emit/glue.rs` reimplements `snake_case`, `pascal_case`, `rust_ident`, and a Rust keyword
list from `emit/rust.rs`; `emit/proto.rs` also duplicates case conversion. `diff.rs`
duplicates `type_kind_name`/`source_type` from `emit/convert.rs`. The copies can drift.

## Acceptance criteria

- [ ] Rust case conversion, identifier escaping, and keyword handling live in one shared
      helper used by rust, glue, and proto emitters
- [ ] `TypeDefKind`/`TypeExpr` rendering lives in one shared helper used by diff and
      conversions
- [ ] generated output is byte-for-byte unchanged
- [ ] `ci/check-generated.sh`, the full suite, and the fuzz stable check pass
