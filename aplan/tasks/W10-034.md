## Why

`emit/glue.rs` reimplements `snake_case`, `pascal_case`, `rust_ident`, and a Rust keyword
list from `emit/rust.rs`; `emit/proto.rs` also duplicates case conversion. `diff.rs`
duplicates `type_kind_name`/`source_type` from `emit/convert.rs`. The copies can drift.

## Acceptance criteria

- [x] Rust case conversion, identifier escaping, and keyword handling live in one shared
      helper used by rust, glue, and proto emitters
- [x] `TypeDefKind`/`TypeExpr` rendering lives in one shared helper used by diff and
      conversions
- [x] generated output is byte-for-byte unchanged
- [x] `ci/check-generated.sh`, the full suite, and the fuzz stable check pass

## Verification

- The shared Rust helpers are exercised by `escapes_keywords_and_compiles_generated_code`,
  `emits_every_rust_mapping_row_as_a_golden`, and `glue_output_matches_golden`.
- The shared protobuf naming helpers are exercised by
  `mapping_golden_is_deterministic_and_compiles`.
- Shared type rendering is exercised by `diff_reports_a_type_kind_change`,
  `diff_reports_every_change_category_and_distinguishes_compatibility`, and
  `generated_conversions_compile_and_apply_across_two_versions`.
- `ci/check-generated.sh` confirms committed example output is byte-for-byte unchanged; the full
  workspace suite, MSRV 1.88, Clippy, rustdoc, security, semver, release scripts, and the fuzz
  stable check pass.
