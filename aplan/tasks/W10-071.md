## Why

Audit finding B14 (medium, reviewer-run). With `--serde`:

- `option<option<T>>`: `Some(None)` serializes as `null` and deserializes as `None`;
- a NaN float serializes as `null` and then fails to deserialize;
- the Serde fixture has no nested option or result although the specification says the
  round trip covers them;
- the JSON names are not documented: a field named `self` is keyed `self_`, enum cases are
  `"DoneNow"`, results are `{"Ok": …}`. The JSON Schema emitter describes `{"ok": …}` and
  WIT names, so the two JSON surfaces of one contract differ.

## Acceptance criteria

- [ ] nested options round-trip or `--serde` refuses a contract that has them, with a test
- [ ] the float behaviour is specified
- [ ] field, case, and result keys are specified in `emitters.md`; the decision whether they
      equal the JSON Schema emitter's names is recorded, and if they do, a test validates
      serialized values against the generated schema
