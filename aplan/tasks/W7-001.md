## Why

The current compiler includes conversions, order fingerprints, JSON Schema, worlds, and
project configuration; release it as the first pre-1.0 version rather than waiting for a
broader ecosystem.

## Acceptance criteria

- [ ] workspace and CLI dependency versions are 0.2.0, with a refreshed lockfile
- [ ] README status and a dated 0.2.0 changelog section describe the release
- [ ] the release gates, install check, tag, and trusted publish run are recorded

## Why it is untestable

Release coordination is proved by the tag, release run, install check, and changelog record,
not by a Rust test.
