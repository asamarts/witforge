## Why

Once Wave 1 proves the shared language-neutral convertibility analysis extracted from `convert.rs` (`W13-012`), Java 21+ and C# 12+ / .NET 8+ need identical bidirectional cross-version value conversion semantics (defaulting added `option`/`list`/`map` fields on minor upgrades, reporting removed required members and unknown cases, handling cross-major `DepLayout` pinned dependencies, and omitting non-convertible types across major boundaries with explicit notes).

## Acceptance criteria

- [ ] Emit deterministic bidirectional cross-version conversion modules for adjacent live version pairs in Java 21+ and C# 12+ using the shared `W13-012` convertibility model
- [ ] Cover minor additions (defaulted `option`/`list`/`map`), removed required members, unknown enum/variant cases, pinned `deps/` across majors, and cross-major omission notes with offline golden tests and CI compile/round-trip evolution tests
- [ ] Keep existing `0.7.0+` public library APIs strictly additive and update `docs/design/public-api-inventory.txt` if new public items are added
