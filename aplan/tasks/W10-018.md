## Why

Hosted macOS CI can compile the workspace and still fail `dependency_glue_roundtrips_a_foreign_value` with `no usable prost rlib combination`. The test harness discovers and probes Cargo artifacts itself; that discovery must be deterministic across target platforms and concurrent workspace tests.

## Acceptance criteria

- [x] the failure is explained from the exact hosted log and harness implementation
- [x] generated glue compile/run tests use deterministic Cargo artifact metadata rather than guessing compatible rlib combinations
- [x] both dependency glue suites pass on Linux and hosted macOS without weakening generated-code compilation coverage
- [x] full workspace and hosted CI pass
