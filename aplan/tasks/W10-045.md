## Why

Audit findings A1 (critical) and A7 (medium). A released named type can change kind without
any gate noticing, as long as the new members have new names. The lockfile then keeps the old
members as reserved entries of one kind next to live entries of another kind under the same
parent, and every field that refers to the type silently changes its wire shape.

## Reproduction (re-run 2026-11-18)

```wit
// wit/v0.1/c.wit, locked with --first and listed in wit/released
package ex:k@0.1.0;
interface types {
  enum color { red, green }
  record r { c: color }
}
// wit/v0.2/c.wit: the same, except
//   record color { hue: u32 }
```

`witforge lock wit/v0.2 --against wit/v0.1/wire.lock`, `check --against`, `proto`, `glue`,
and `schema` all exit 0. `diff` prints `kind-changed … wire:compatible`. In `v0.proto`,
`r.c = 1` changes from `optional TypesColor` (an enum) to a message, and `message TypesColor`
carries no `reserved 1, 2` for the old cases. Only `witforge rust` refuses, through the
conversion generator. The reviewer ran all twelve ordered pairs among enum, flags, record,
and variant with the same result.

Code: `model.rs:427-435`, `lock.rs:514-562`, `diff.rs:707-726`, `proto.rs:627`.

## Proposed fix

Refuse a parent whose live and reserved members do not all have one kind. This needs no
lockfile format change. A transition between two memberless shapes is already caught because
the canonical type of every referring member changes.

## Acceptance criteria

- [ ] reconciliation refuses, with exit 1 and a message naming the parent and both kinds, any
      contract that would give one parent members of two kinds
- [ ] `check` refuses a lockfile that already holds a mixed-kind parent
- [ ] a test covers all twelve ordered kind pairs for `lock --against`, `check --against`,
      `proto`, `glue`, and `schema`
- [ ] `diff` classifies a kind change as wire-breaking and `diff.md` says so
- [ ] proto output reserves every reserved number and name, including the method ids of an
      interface that no longer exists (reviewer-run: those are dropped today)
- [ ] the changelog tells an owner of an unreleased draft that already mixes kinds how to
      recover (rename the type)
