## Why

C# 12+ / .NET 8 LTS+ matches WIT primitives nearly 1:1 (`byte`/`ushort`/`uint`/`ulong`/`sbyte`/`short`/`int`/`long`, `System.Text.Rune`, `sealed record`, `#nullable enable`), enabling idiomatic zero-dependency .NET contract libraries directly from WIT.

## Acceptance criteria

- [ ] Implement additive `witforge::emit::csharp` (`#[non_exhaustive]` `CSharpOptions`, no `Copy`), `witforge csharp` CLI, and `[project.<name>.csharp]` config wired into `ensure_distinct_output_roots` and `witforge generate`, emitting C# 12+ / .NET 8 LTS+ code (`#nullable enable`, `sealed record`, `abstract record` + `sealed record` variant/result hierarchies, `enum`, `System.Text.Rune`, `IReadOnlyList`, `IReadOnlyDictionary`, interfaces, `worlds`, `deps/` with `DepLayout`, XML doc comments, `[Obsolete]`)
- [ ] Enforce deterministic LF-only nested output via `output.rs`, ownership headers, keyword escaping (`@...`), and `--check` drift detection
- [ ] Add offline golden/unit tests in `cargo test --workspace --locked`, update `docs/design/public-api-inventory.txt`, and document CLI/config keys in `docs/guide/reference.md`
