## Why

Audit finding D7 (idea, not a defect). The emitted `.proto` carries no file options
(`go_package`, `java_package`, `csharp_namespace`, …). A Go consumer cannot compile it with
`protoc-gen-go` without passing a mapping flag per file. The cross-language conformance
profile is `W11-034`.

## Acceptance criteria

- [ ] record what one non-Rust adopter needs to compile the emitted schema
- [ ] specify options as configuration that does not affect wire identity or the lockfile
- [ ] implement with a golden test, or record a decline with a revisit trigger
