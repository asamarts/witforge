## Why

Audit finding D7 (idea, not a defect). The emitted `.proto` carries no file options
(`go_package`, `java_package`, `csharp_namespace`, …). A Go consumer cannot compile it with
`protoc-gen-go` without passing a mapping flag per file. The cross-language conformance
profile is `W11-034`.

## Decision

Default chosen while documenting the task on 2026-11-19, not an owner decision.

The task is an evaluation, and its result is one of two. Options are emitted
when a non-Rust adopter's build needs them and neither a mapping flag of the
language plugin nor managed mode in `buf` serves it. Otherwise the task records
a decline in `docs/design/emitters.md` and documents those two ways.

## Edge cases

- One option per target language: `go_package`, `java_package` and
  `java_multiple_files`, `csharp_namespace`, and the rest. Each proto file needs
  its own value, a dependency's file included.
- File options are not wire identity, and the lockfile does not change.
- `buf breaking` with its default rules reports a changed file option. A consumer
  that turns options on sees that once.
- The fixtures have no options, so `ci/check-buf-history.sh` is unaffected.
- What works without a change to the tool: mapping flags of the language plugin,
  and managed mode in `buf`. A decline documents these.
- The task waits for a non-Rust adopter (`W10-001`), whose build is the evidence.

## Acceptance criteria

- [ ] record what one non-Rust adopter needs to compile the emitted schema
- [ ] specify options as configuration that does not affect wire identity or the lockfile
- [ ] the result follows the rule under Decision: options are emitted, with a golden test,
      or the decline and the two ways that work without them are recorded
