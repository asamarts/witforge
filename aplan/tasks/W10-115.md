## Why

Imperative `recording_imports` toggling during protobuf wrapper synthesis could miss a transitive cross-package reference computed before `ensure_wrapper` ran (for example, `WrapperKind::ListElement` referencing a transitive dependency wrapper inside a named list in a dependency package). Deriving `import "..."` lines directly from cross-package type tokens on non-comment lines of the rendered protobuf body guarantees that every emitted cross-package reference has its import and no unused dependency import is emitted.
