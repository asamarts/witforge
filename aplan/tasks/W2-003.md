## Why

Reconcile is where append-only behavior, reservations, reintroduction refusal,
and protobuf number bounds meet. It must be transactional from the caller's view:
no write on failure.

## Acceptance criteria

- [x] next-number allocation skips 19000–19999 and refuses past the maximum
- [x] removed members reserve and reintroduced reserved members are refused
- [x] type/kind mismatches and reserved-number collisions are rejected; previous-baseline released checks live in W2-004
- [x] no-write-on-error and atomic rendering are tested
- [x] boundary tests cover number exhaustion and reserved-range skipping; property tests live in W2-006
