## Why

witforge's plan has outgrown a checkbox list. aplan makes task status, dependency
order, and closure evidence machine-checkable, and this repository is a pilot for
the tool as well as its first user.

## Acceptance criteria

- [x] `.aplan.yml`, `aplan/tasks/`, `aplan/README.md`, and `docs/aplan-pilot.md` exist
- [x] `AGENTS.md` carries the generated block and project instructions
- [x] `CLAUDE.md` is a symlink to `AGENTS.md`
- [x] `aplan check`, `aplan verify`, and `aplan export-agents-md --check AGENTS.md` pass
- [x] The plan maps the remaining witforge work into prioritized cuts

## Why it is untestable

This is the plan, policy, and agent-contract change itself. No Rust test would
fail if the plan were reverted; `aplan check`, `aplan verify`, and the generated
agent-block check are the gates for it.
