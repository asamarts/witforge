## Why

0.1.0 was published by hand. 0.1.1 ships the W6-010 and W6-011 fixes, and is
the first release that `release.yml` publishes through crates.io trusted
publishing, which no run has exercised yet.

## Acceptance criteria

- [ ] the version, the CLI's requirement, `Cargo.lock`, the dated changelog
  section, and the README status say 0.1.1
- [ ] `release.yml` publishes both crates from the `v0.1.1` tag and creates the
  GitHub release
- [ ] `cargo install witforge-cli --version 0.1.1 --locked` installs it

## Why it is untestable

The proof is the published artifact, the release run, and the tag, not a unit
test.
