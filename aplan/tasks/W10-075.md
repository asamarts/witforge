## Why

Audit finding C3 (high, re-run in the first audit pass). The guard that stops a generator
from writing into the WIT root compares lexically normalised paths
(`emit/output.rs:289-311`). With `witlink` a symlink to `wit`,
`witforge rust wit --out missing/../witlink/v0.1` writes generated files into `wit/v0.1`,
next to the contract and its lockfile, and the next run's cleanup can remove files there.

## Acceptance criteria

- [ ] the guard compares canonical paths, resolving the deepest existing ancestor when the
      output directory does not exist yet
- [ ] tests cover `..` after a missing component, a symlinked ancestor, and a symlinked
      output directory
- [ ] the same guard protects `released` directories
