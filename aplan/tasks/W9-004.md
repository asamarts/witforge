## Why

W9-001 records package-qualified foreign types but leaves dependency bindings external.
The local generated code cannot compile without the consumer supplying matching modules and
schemas, so a dependency release needs generated bindings.

## Acceptance criteria

- [x] dependency interfaces are included in the owned model with package identity
- [x] Rust emits dependency modules that make local foreign-type references compile
- [x] protobuf emits dependency schemas and imports them from the root schema
- [x] dependency models are validated and consistent across contract versions
- [x] tests compile generated Rust and protobuf for a local package importing a dependency
- [x] the dependency design document describes the generated binding layout
