## Why

Once `W12-010` has switched GitHub Pages to the Astro + Starlight workflow (with all canonical `/witforge/docs/.../` routes and legacy `.html` redirects live), the obsolete Jekyll files (`docs/_config.yml`, `docs/assets/css/style.scss`) and legacy YAML frontmatter (`layout: default`, `title: ...`) on `docs/*.md` can be retired with zero live-site downtime. At the same time, `crates/witforge-cli/tests/docs.rs` must switch from validating `docs/_config.yml` / `jekyll-relative-links` to validating `docs/SUMMARY.md`, canonical Starlight URLs, legacy redirects, and a Rust-level em-dash guard, and `crates/witforge-cli/tests/tooling.rs` should run `node --test site/scripts/test-scripts.mjs` as part of `cargo test`.

## Decision

Default chosen while documenting the task on 2026-11-25, not an owner decision:

- Sequence `W12-009` **after** `W12-010` (not before) so deleting `docs/_config.yml`, stripping Jekyll frontmatter, and switching `README.md` links to `/witforge/docs/.../` never creates a broken legacy Jekyll window or 404s on live GitHub Pages.
- Update `documentation_links_and_anchors_resolve_on_github_and_pages` in `crates/witforge-cli/tests/docs.rs` to:
  1. Require `docs/SUMMARY.md` instead of `docs/_config.yml` and assert that every published `docs/**/*.md` file (excluding `docs/design/`, `docs/aplan-pilot.md`, `docs/SUMMARY.md`, and `docs/guide/index.md`) appears in `docs/SUMMARY.md`, and every `SUMMARY.md` entry exists on disk.
  2. Map absolute Pages URLs (`https://asamarts.github.io/witforge/...`) accurately: `/` -> `site/src/pages/index.astro`, `/outputs/` -> `site/src/pages/outputs.astro`, `/docs/` -> `docs/index.md`, `/docs/quickstart/` -> `docs/quickstart.md`, `/docs/<slug>/` -> `docs/guide/<slug>.md`, and legacy URLs (`/guide/`, `/quickstart.html`, `/guide/*.html`) via `site/scripts/redirects.json`.
  3. Keep verifying relative `.md` links and anchors on GitHub across all Markdown files including `docs/guide/index.md`.
- Add `published_docs_and_readme_contain_no_em_dashes` in `crates/witforge-cli/tests/docs.rs` failing if `README.md`, `docs/SUMMARY.md`, `docs/index.md`, `docs/quickstart.md`, or any `docs/guide/*.md` contains `U+2014`, `&mdash;`, `&#8212;`, or `&#x2014;`.
- Add `site_script_unit_tests_pass_under_node` in `crates/witforge-cli/tests/tooling.rs` (matching `action_unit_tests_pass_under_node`'s pattern) running `node --test site/scripts/test-scripts.mjs` across Linux, macOS, and Windows CI.
- Update `README.md`'s absolute Pages links to canonical `/witforge/docs/.../` URLs while keeping `witforge::diagnostic::HELP_BASE_URL` unchanged (pinned in `docs/design/public-api-inventory.txt`).
- Update `ci/README.md` to reflect that legacy `docs/_config.yml` is retired and `docs.rs` validates `docs/SUMMARY.md` + `redirects.json`.

## Approach

1. Remove `docs/_config.yml` and `docs/assets/css/style.scss` (removing empty `docs/assets/`).
2. Remove legacy Jekyll YAML frontmatter (`layout: default` / `title: ...`) from published `docs/*.md` files (`docs/index.md`, `docs/quickstart.md`, and `docs/guide/*.md`) so raw GitHub viewing stays crisp and clean.
3. Update `README.md` absolute Pages links (`https://asamarts.github.io/witforge/guide/*.html` -> `https://asamarts.github.io/witforge/docs/*/`) while preserving all version patterns checked by `ci/check-version-references.sh` and executable snippets tested by `readme_commands_run_verbatim`.
4. Update `crates/witforge-cli/tests/docs.rs`, `crates/witforge-cli/tests/tooling.rs`, and `ci/README.md`.
5. Run the full workspace Rust verification suite (`cargo fmt --check`, `cargo clippy`, stable and MSRV 1.88 `cargo test`, `ci/check-release.sh`, `ci/check-public-api.sh`, `npm --prefix site run verify`, `aplan check-docs`, `git diff --check`).
