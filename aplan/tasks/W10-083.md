## Why

Audit finding C12 (high for adopters). The append-only guarantee depends on released
directories never changing. That is enforced only by `ci/check-release-freeze.sh`, a script
in this repository that is in no crate, release archive, or Action. An adopter who follows
the guides has `wit/released` and nothing that stops an edit to `wit/v0.1/wire.lock` plus a
matching regeneration from passing every `witforge` command.

Reviewer-read: this repository's own CI runs the freeze check on the test fixtures and not on
`examples/evolved/wit/released`.

## Acceptance criteria

- [ ] a `witforge` command compares every directory listed in `released` with a Git
      revision (default: the merge base with the default branch) and exits 1 when a released
      file changed, a released entry disappeared, or a symlink was introduced
- [ ] the Action exposes it and the CI guide's snippet uses it
- [ ] the shell script is replaced by, or reduced to a call of, the command
- [ ] this repository's CI runs it on the fixtures and on `examples/evolved`
