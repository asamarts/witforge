## Why

The property generator only builds one record plus one function with primitive, list,
option, and result shapes. The golden and conformance fixtures cover the rest, but the
input-level property suite does not exercise variants, enums, flags, aliases, named
structural types, worlds, or two-version conversion planning. A model shape that hand-written
fixtures miss can still panic an emitter.

## Acceptance criteria

- [x] the property generator emits every `TypeDefKind` and every `TypeExpr`, including named
      aliases and named structural types
- [x] generated models pass the Rust, protobuf, JSON Schema, and glue emitters without
      panicking
- [x] the two-version versions fixture exercises `rust` conversion planning and `diff`
      (`compare_with_impacts`) without panicking
- [x] lockfile parse/render properties and the existing emitter property remain green
- [x] `cargo test -p witforge --test properties` and the full workspace suite pass

## Verification

Close on the named properties test.
