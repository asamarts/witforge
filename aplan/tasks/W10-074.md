## Why

Audit findings B15 (part) and B16 (medium, re-run in the first audit pass). Generated Rust
committed into a consumer's crate fails that crate's ordinary gates:

- four generated files differ under `cargo fmt --check`;
- `#![warn(missing_docs)]` reports generated items;
- a type-only interface gets an empty `pub trait Types {}` and an empty
  `enum TypesMethod { …_UNSPECIFIED = 0 }`;
- a function without a result is emitted as `fn ping(&self) -> ();`.

The only consumer wraps every generated module in
`#[rustfmt::skip] #[allow(warnings, clippy::all, clippy::pedantic)]`. No witforge document
tells an adopter to do that.

## Decision

Decided by the owner on 2026-11-19: the output is made clean, not exempted. It is
in rustfmt's default style, every public item has a doc comment, an interface
without functions gets no trait, and a function without a result is written
`fn ping(&self);`. A consumer with a non-default `rustfmt.toml` puts
`#[rustfmt::skip]` on the module declaration, and the adopter guide (`W10-091`)
says so. The task ships in 0.6.0 (`W10-069`).

Found while documenting the task on 2026-11-19, after the decision: the empty
method enum of a type-only interface is in the `.proto` file, not in the plain
Rust (run 2026-11-19: `enum TypesMethod { TYPES_METHOD_UNSPECIFIED = 0; }` in
`v0.proto`). It is released schema. Deleting it is an `ENUM_NO_DELETE` finding of
`buf breaking`, so `ci/check-buf-history.sh` would fail against every earlier
release for every fixture with a type-only interface, and that gate is a 1.0
criterion. Default, for the owner to confirm: the trait goes, and the proto enum
stays. It costs nothing on the wire, and an interface that later gains a function
needs it.

## Edge cases

- rustfmt's default style depends on the style edition, and edition 2024 changed
  it. The harness formats the output in a 2021 crate and in a 2024 crate. Where
  one text cannot satisfy both, the emitter changes the construct; if that is
  impossible, the guide says which style edition the output follows.
- Order of consecutive `mod` and `use` items: rustfmt sorts them, and the two
  style editions sort `v0_10` and `v0_2` differently. A root with ten or more
  versions is in the test.
- Long signatures. Fully qualified paths make lines over 100 columns common, and
  the emitter has to break them where rustfmt does. Type aliases that shorten a
  line are an option.
- No rustfmt binary is run by the generator (`emitters.md` section 1); the
  harness of `W10-068` runs `cargo fmt --check` on the result.
- `missing_docs`: modules, struct fields, enum variants, trait methods, type
  aliases, constants, and functions. An item without WIT documentation gets a
  one-line comment that names its WIT identity.
- Removing the empty trait removes `pub trait Types {}` and its re-export at the
  version root. A consumer that names it stops compiling; that is a migration
  entry. `interface error { enum error }` is refused today because of that trait
  (`W10-059`) and becomes valid.
- An interface that has functions in one minor and none in another of the same
  major.
- `emitters.md` describes today's output: section 3.1 shows an empty trait and
  one-line signatures (corrected on 2026-11-18), and section 3.5 says that a
  function with no result returns `()`. Both sections are rewritten with this
  task.
- The per-version modules of released versions change. They are regenerated, not
  edited; the migration section says that this release changes them.
- Glue and `convert.rs` are generated Rust too and meet the same three gates.

## Acceptance criteria

- [ ] generated Rust for every fixture passes `cargo fmt --check`, `clippy -D warnings`, and
      `-D missing_docs` in the compile harness (`W10-068`), in an edition 2021 crate and
      in an edition 2024 crate
- [ ] no trait is emitted for an interface without functions; the proto method enum of
      such an interface stays, and `emitters.md` says why
- [ ] unit-returning functions have no `-> ()`
- [ ] `ci/check-buf-history.sh` passes for every fixture against every earlier release
