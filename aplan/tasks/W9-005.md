## Why

W9-004 emits dependency types, but a world still cannot name a dependency interface:
`subset` refuses every interface from another package, and glue cannot convert a local
value whose type lives in `deps/`. The 0.4.0 dependency surface is therefore types-only
unless the world and glue paths agree with the generated bindings.

## Acceptance criteria

- [ ] a world may import or export a named interface from a standard `deps/` package
- [ ] the model preserves the dependency package identity of a foreign world interface
- [ ] Rust world metadata and generated traits resolve the foreign interface module
- [ ] protobuf imports the dependency schema used by the world interface
- [ ] glue emits conversion modules for foreign values and dependency interfaces
- [ ] tests compile a local world importing a dependency interface and round-trip a foreign value
- [ ] the dependency design document states the supported foreign-interface and glue surface and its refusals
