## Why

The current documentation site at `https://asamarts.github.io/witforge/` runs on GitHub Pages' legacy Jekyll theme (`jekyll-theme-minimal`), which offers no dark mode, no client-side search, no structured sidebar, no visual brand identity, and no promotional landing page explaining witforge's capabilities. Refreshing the site onto the same modern Astro + Starlight static architecture used by `asamarts/ayaml`, while giving witforge its own distinct blue visual identity and custom logo, creates the foundation for the full rebuild.

## Why it is untestable

This task establishes static frontend configuration, CSS custom properties, font packages, and SVG brand assets rather than Rust library or CLI behavior covered by `.aplan.yml`'s Cargo test runners. No `cargo test` can fail if the CSS palette or logo geometry is reverted; verification runs through `npm --prefix site ci`, `npx --prefix site astro check`, contrast math verification, `git diff --check`, and visual inspection of the rendered brand assets.

## Decision

Decided by the owner on 2026-11-25:

- Use the Astro + Starlight stack under `site/`, following the structural conventions of `asamarts/ayaml`.
- Differentiate visually from `ayaml`: use a blue highlight and emphasis palette instead of terracotta orange/red, and design a unique, intuitive, elegant, and engaging logo for witforge.

Default chosen while documenting the task on 2026-11-25, not an owner decision:

- Palette tokens (Cobalt/Sapphire Blue on cool steel slate surfaces, mathematically verified WCAG 2.1 AA+ >= 4.5:1 for all text on every surface and >= 3:1 for interactive control borders):
  - Light mode: `#ffffff` canvas (`--bg`), `#f6f8fc` surface (`--surface`), `#eef2f8` surface-2 (`--surface-2`), `#0f172a` ink (`--ink`), `#263244` body text (`--text`), `#4e5d73` muted text (`--muted`), `#d8e1ee` divider (`--rule`), `#6c7c94` UI control border (`--border-strong`, >= 3.78:1 on `surface-2`), `#1d4ed8` accent (`--accent`), `#1e40af` accent hover (`--accent-hover`), `#1e3a8a` strong accent (`--accent-strong`), `#eff6ff` accent wash (`--accent-wash`), `#bfdbfe` accent divider (`--accent-border`), `#1d4ed8` / `#1e40af` CTA fill (`--accent-fill` / `--accent-fill-hover`) with `#ffffff` CTA ink (`--on-accent`, 6.70:1+), `#0369a1` wire accent (`--wire`), `#166534` ok (`--ok`, 6.35:1 on `surface-2`), `#92400e` warn (`--warn`, 6.31:1 on `surface-2`), `#be123c` error (`--err`, 5.59:1 on `surface-2`).

- Custom SVG logo ("Forged Prism / Contract Die"): a crisp 32x32 beveled hexagonal die mark containing an interlocking geometric "W" channel where one source facet divides into locked parallel projection rails, representing one WIT contract forged into stable multi-target artifacts.
- Keep `og-card.svg` and `og-card.png` version-agnostic (no hardcoded release version) so the social preview stays accurate across releases without churn.

## Approach

1. Initialize `site/package.json` (pinning `astro`, `@astrojs/starlight`, `@fontsource-variable/plus-jakarta-sans`, `@fontsource-variable/inter`, `@fontsource/jetbrains-mono`) and commit `site/package-lock.json`.
2. Configure `site/astro.config.mjs` with `site: 'https://asamarts.github.io'`, `base: '/witforge'`, `trailingSlash: 'always'`, Starlight `disable404Route: true`, `expressiveCode: { themes: ['github-light', 'github-dark'] }`, Starlight `sidebar` loaded safely from `site/src/data/sidebar.json` (falling back to `[]` before `W12-002`), and `tokens.css` + Fontsource stylesheets. Keep `astro.config.mjs` immediately buildable without requiring `W12-003`'s `Header.astro` / `Footer.astro` / `custom.css` yet.
3. Verify bundled Shiki language support for `wit`, `rust`, `proto`, `json`, `toml`, `yaml`, `sh`, and `text` so `wit` code fences highlight cleanly without build warnings.
4. Implement `site/src/lib/site.ts` reading the live workspace version from `../Cargo.toml` (parsing specifically within `[workspace.package]`) and exporting canonical URLs, repo links, crate links, and metadata helpers.
5. Author `site/src/styles/tokens.css` implementing the verified light and dark tokens, typography scale, spacing scale, radii, shadows, and elevation tokens.
6. Design and commit `site/public/favicon.svg` (light/dark adaptive via `@media (prefers-color-scheme: dark)`), `site/src/components/SiteLogo.astro` (inline SVG mark + `witforge` wordmark lockup), `site/public/og-card.svg` (designed with font-metric-safe layout so `rsvg-convert` renders crisp typography without clipping), rendered `site/public/og-card.png` (1200x630), and `site/public/robots.txt`.
7. Add `site/node_modules/`, `site/dist/`, `site/.astro/`, `site/src/content/docs/`, and `site/src/data/sidebar.json` to `.gitignore`, and add `site/public/*.png binary` to `.gitattributes`.

## Edge cases

- `favicon.svg` must stay crisp and recognizable at 16x16 browser tab size as well as 32x32 and 128x128; avoid hairline strokes under 1.5px on the 32x32 grid.
- `site/src/lib/site.ts` must parse `[workspace.package]` `version = "X.Y.Z"` reliably without picking up dependency versions from `Cargo.toml`.
- `og-card.png` must be visually inspected after rendering with `rsvg-convert` (1200x630) to confirm crisp text alignment and zero clipped glyphs with system fallback fonts.
- All tracked text files (`package.json`, `package-lock.json`, `astro.config.mjs`, `tokens.css`, `*.svg`, `robots.txt`, `.gitignore`, `.gitattributes`) must pass `git diff --check` with LF line endings and zero trailing whitespace (required by `.github/workflows/ci.yml`'s `lint` job).
