## Why

Lockfile v2 numbers record fields, variant cases, enum cases, flags, method ids,
and parameters. The model is the single source of that member set.

## Acceptance criteria

- [ ] type members carry kind and canonical type
- [ ] function method ids carry the result type or no type
- [ ] parameters carry their type and function parent
- [ ] aliases and named structural types produce no members
- [ ] source order is deterministic
