## Why

Lockfile v2 numbers record fields, variant cases, enum cases, flags, method ids,
and parameters. The model is the single source of that member set.

## Acceptance criteria

- [x] type members carry kind and canonical type
- [x] function method ids carry the result type or no type
- [x] parameters carry their type and function parent
- [x] aliases and named structural types produce no members
- [x] source order is deterministic
