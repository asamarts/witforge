## Why

Hosted Windows CI (`test (windows-latest)`) on `3dbd063` failed only on
`diff_git_base_compares_working_tree_respects_tmpdir_and_enforces_guards` because:
- `val["new"]["path"]` is a platform filesystem path (`wit\v0.2` on Windows vs `wit/v0.2` on
  Unix) and was compared against `"wit/v0.2"`.
- `file://` shallow-clone URL used raw `fs::canonicalize(&repo).display()`, which produces a
  `\\?\C:\...` verbatim path on Windows instead of RFC 8089 `file:///C:/...`.

## Acceptance criteria

- [ ] Compare `val["new"]["path"]` via `Path::new(...)` and construct RFC 8089 `file:///` URI
      stripping Windows `\\?\` prefix and normalizing backslashes (plus forward `TMP`/`TEMP`
      alongside `TMPDIR`).
- [ ] Hosted CI (`ci ok`) passes green across all 24 jobs including `test (windows-latest)`.
