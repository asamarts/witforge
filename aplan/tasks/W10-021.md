## Why

The 0.5.0 release moved the downstream consumer and left two documentation gaps. alint now
pins 0.5.0 (PR #555), but `docs/design/overview.md` still says 0.4.3; the decision log has no
2026-11-17 release entry; the 0.5.0 changelog does not tell consumers moving from 0.4.3 that
they also pick up the 0.4.4 generated-glue changes; and `diff.md` does not state that `diff`
deliberately accepts a non-canonical but current lockfile while `check` is the canonical-form
gate.

## Acceptance criteria

- [x] `docs/design/overview.md` names alint's current 0.5.0 pin and records the 2026-11-17
      0.5.0 release decision
- [x] the 0.5.0 changelog tells 0.4.3 consumers to regenerate committed glue as well as
      `convert.rs`
- [x] `docs/design/diff.md` states the canonical-form boundary between `diff` and `check`
- [x] `aplan check`, `aplan verify`, `aplan export-agents-md --check`, and `aplan check-docs`
      pass, including any required `--restamp`

This changes documentation only. Reverting it cannot make a configured cargo test fail;
aplan document checks, link checks, and a rendered-doc review are the applicable evidence.
