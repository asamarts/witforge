## Why

Prebuilt Linux archives currently target `gnu` on Ubuntu 24.04 (`glibc >= 2.39`), failing on Ubuntu 22.04 LTS, Debian 12, RHEL 9, and Alpine containers. Because `witforge` is pure Rust, static `musl` archives run on every Linux distribution and container.

## Decision

- Add `x86_64-unknown-linux-musl` and `aarch64-unknown-linux-musl` to `.github/workflows/release.yml` alongside the existing `gnu` targets (so `cargo-binstall` and existing URLs stay intact).
- Update `action/index.js` so Linux selects `musl` for versions `>= 0.8.0` and keeps `gnu` for `<= 0.7.x`.

## Acceptance criteria

- [x] `release.yml` builds, attests, and smoke-tests both `x86_64-unknown-linux-musl` and `aarch64-unknown-linux-musl` alongside `gnu`
- [x] `action/index.js` selects `musl` on Linux for `>= 0.8.0` and `gnu` for `<= 0.7.x`
- [x] `action/test.js` (and `cargo test -p witforge-cli --test tooling`) verifies version-dependent Linux target selection
- [x] Release and install documentation lists the static `musl` targets
