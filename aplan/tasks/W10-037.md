## Why

The Action uses `fetch` for the latest release and asset downloads without an abort timeout,
so a stalled network can hang until the job timeout. Local repository tests and CI helpers use
`std::env::temp_dir()`/`${TMPDIR:-/tmp}`, which on this shared host can consume the shared
tmpfs unless `TMPDIR=~/.tmp` is set.

## Acceptance criteria

- [ ] Action latest-release and download requests have a bounded timeout/abort path
- [ ] a unit test or existing Action smoke covers the timeout helper or records why only the
      hosted Action run can prove it
- [ ] `ci/README.md` documents `TMPDIR=~/.tmp` for local test runs or a test scratch helper
      removes the need
- [ ] action tests, actionlint, shellcheck, and the full suite pass
