## Why

Audit finding F6 (medium). The public documentation shows the commands and the generated
text but not how an adopter makes them part of a crate. Missing:

- wiring: where generated modules go, the `build.rs` for prost, the module layout the
  `--plain-root` and `--proto-root` values must match, and how to treat generated code under
  rustfmt and lints;
- installing a prebuilt binary and verifying it;
- `--lock`, `--released`, and the configuration key `released`, which appear only in design
  documents excluded from the site;
- migrating between witforge releases (what to regenerate, what can change);
- starting a new major (see `W10-093`).

## Why it is untestable

This is documentation; the commands it contains are covered by the snippet test of `W10-042`.

## Edge cases

- Running the guide's commands means building a crate with prost. Take the
  guide's files from its fenced blocks and build them in the compile harness
  (`W10-068`); the documentation test of `W10-042` runs only `witforge` commands.
- Two layouts exist: generated code committed under `src/`, and generated code
  written by `build.rs`. The guide takes the committed one, because `--check` in
  CI needs it, and says why.
- prost-build needs a protobuf compiler, or `protox`, as this repository's tests
  use. Name the prost versions the glue supports (`W10-059`).
- The values of `--plain-root` and `--proto-root` have to match the module layout
  the guide builds, in the forms `W10-064` accepts.
- After `W10-074` generated code needs no attribute. The exception is a crate
  with a non-default `rustfmt.toml`, which puts `#[rustfmt::skip]` on the module
  declaration.
- Installing: `cargo install --locked` with a version, and a prebuilt archive with
  its checksum. Attestation is added when `W10-087` provides it.
- The reference of options and configuration keys is compared with the argument
  definitions by a test, so a new flag fails until it is documented.
- The migration page links to the changelog's migration section of each release.
  It does not copy it.
- `--lock`, `--released`, and the `released` configuration key, with the default
  location of the manifest.
- Starting a new major is written with `W10-093`.

## Acceptance criteria

- [x] a guide page takes an empty crate to a compiling round trip, and its commands are run
      by the documentation test from `W10-042`
- [x] every CLI option and configuration key is documented on the public site
- [x] a migration page lists, per release, the changes that alter generated output
