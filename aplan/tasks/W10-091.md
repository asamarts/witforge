## Why

Audit finding F6 (medium). The public documentation shows the commands and the generated
text but not how an adopter makes them part of a crate. Missing:

- wiring: where generated modules go, the `build.rs` for prost, the module layout the
  `--plain-root` and `--proto-root` values must match, and how to treat generated code under
  rustfmt and lints;
- installing a prebuilt binary and verifying it;
- `--lock`, `--released`, and the configuration key `released`, which appear only in design
  documents excluded from the site;
- migrating between witforge releases (what to regenerate, what can change);
- starting a new major (see `W10-093`).

## Acceptance criteria

- [ ] a guide page takes an empty crate to a compiling round trip, and its commands are run
      by the documentation test from `W10-042`
- [ ] every CLI option and configuration key is documented on the public site
- [ ] a migration page lists, per release, the changes that alter generated output

## Why it is untestable

This is documentation; the commands it contains are covered by the snippet test of `W10-042`.
