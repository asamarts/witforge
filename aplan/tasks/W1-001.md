## Why

The lockfile and every emitter need one representation of types, docs, stability,
functions, and worlds that does not expose `wit-parser` types or arena IDs.

- [x] `wit-parser` does not appear in the public model API
- [x] unit tests cover build invariants, source order, docs/stability, the opaque API, and refused constructs
