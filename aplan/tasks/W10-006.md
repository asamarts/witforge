## Why

An imported dependency interface can silently lose unsupported items, glue does not reject
dependency packages that map to one Rust module, and JSON Schema classifies the same
cross-version dependency violation differently from the other generators.

## Acceptance criteria

- [ ] a dependency interface exposed by a root world is validated as a whole and unsupported
      contents are refused rather than omitted
- [ ] unsupported dependency items remain skippable only when no root type or world exposes them
- [ ] glue refuses colliding dependency module names before writing invalid Rust
- [ ] all four generators classify the same dependency contract violations as `ContractError`
- [ ] focused cargo tests reproduce every pre-fix failure and pass after the fix
