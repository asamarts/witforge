## Why

An imported dependency interface can silently lose unsupported items, glue does not reject
dependency packages that map to one Rust module, and JSON Schema classifies the same
cross-version dependency violation differently from the other generators.

## Acceptance criteria

- [x] a dependency interface exposed by a root world is validated as a whole and unsupported
      contents are refused rather than omitted
- [x] unsupported dependency items remain skippable only when no root type or world exposes them
- [x] glue refuses colliding dependency module names before writing invalid Rust
- [x] all four generators classify the same dependency contract violations as `ContractError`
- [x] focused cargo tests reproduce every pre-fix failure and pass after the fix
