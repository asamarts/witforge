## Why

GitHub retired Node 20 for JavaScript Actions, but the published Action and current metadata
still declare `runs.using: node20`. The JavaScript unit tests bypass Action metadata, so CI can
remain green while `uses: asamarts/witforge@...` is unsupported.

## Why it is untestable

The regression is GitHub selecting the Action metadata runtime and executing `uses: ./` on a
hosted runner. The configured evidence runners list Rust tests only; no cargo test can execute
GitHub's JavaScript-Action host. The workflow run is the proof, with the dependency-free Node
test retained as a local unit check.

## Acceptance criteria

- [x] the Action declares the supported Node 24 runtime
- [x] CI invokes `uses: ./` on a GitHub-hosted runner and exercises a real install and command
- [x] dependency-free Action unit tests remain green
- [x] the Action and README documentation name the supported runtime and release behavior
