## Why

Checked Go protobuf glue targeting `google.golang.org/protobuf` (`protoc-gen-go` + `protojson`, paired with `W11-039`'s `go_package` option) lets Go services and plugins exchange WIT contract values with Rust, TypeScript, and Python endpoints with exact decode parity.

## Acceptance criteria

- [x] Implement additive opt-in Go checked protobuf glue (`witforge go-glue` / `[project.<name>.go-glue]` wired into `ensure_distinct_output_roots` and `witforge generate`) targeting `google.golang.org/protobuf` (`ToProto` / `FromProto`, per-function request/response helpers, `Method` constants, structured `*GlueError` implementing `error`)
- [x] Enforce all 13 rows of the WIT decode profile for both binary (`proto.Marshal`/`Unmarshal`) and proto3-JSON (`protojson`) payloads
- [x] Add offline golden/unit tests in `cargo test --workspace --locked`, add a SHA-pinned Go 1.22+ conformance CI job in `.github/workflows/ci.yml` running `go test` against `W11-034` fixtures, update `docs/design/public-api-inventory.txt`, and document CLI/config keys in `docs/guide/reference.md`
