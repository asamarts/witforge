## Why

Released-directory freezing covers memberless types and docs-only patches by
forbidding them. If a consumer needs docs-only patches, the policy needs an
explicit semantic-diff or inventory rule rather than a workaround.

## Acceptance criteria

- [x] the demand and version-directory shape are specified
- [x] a type/interface/world inventory option is evaluated
- [x] any relaxation still forbids wire and generated-API drift
- [x] tests cover a docs-only change and a memberless addition

## Decision

Declined for 0.x/1.0. Draft docs-only changes are accepted without wire or API-shape changes;
memberless additions in a new minor have no lock entry; released docs are guarded by the release
freeze. A patch directory such as `v0.1.1` is not a supported version directory. The evaluation
and the concrete tests are in [`docs/design/overview.md`](../../docs/design/overview.md#103-docs-only-patches-and-memberless-inventory-w6-006).
