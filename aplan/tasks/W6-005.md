## Why

Consumers with several roots and emitters repeat `--out`, `--plain-root`, and
`--proto-root` in every invocation. A config file can make that reproducible.

## Acceptance criteria

- [x] the config format and precedence are specified
- [x] CLI flags override config
- [x] unknown keys are errors
- [x] the existing command line remains a valid fallback
- [x] tests cover single-root and multi-root projects
