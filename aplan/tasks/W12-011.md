## Why

Local builds and static link checkers verify structure, but only an adversarial audit of the live deployed site at `https://asamarts.github.io/witforge/` proves that real GitHub Pages routing, base-path asset loading, Pagefind search indexing, legacy `.html` fragment redirects, responsive layouts, dark/light contrast, SVG logo rendering, and natural prose quality all hold end-to-end.

## Why it is untestable

Live GitHub Pages HTTP behavior, visual layout polish, cross-viewport rendering, keyboard usability, and editorial tone are verified by live inspection and automated HTTP checks against the deployed URL rather than by `.aplan.yml`'s local Cargo test runners.

## Decision

Default chosen while documenting the task on 2026-11-25, not an owner decision:

- Treat any visual glitch, clipped SVG text, broken base-path asset, broken Pagefind search query, dropped `#wfxxxx` redirect fragment, console error, contrast issue, em dash, or unnatural AI-style phrasing as a blocking defect to fix before closing `M-p12`.
- Include `aplan/tasks/W12-011.md` in `paths:` so that if the live audit finds zero defects and records its complete verification log under `## What was done`, the closure commit passes `aplan verify` cleanly without dummy edits.
