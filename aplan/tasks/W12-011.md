## Why

Local builds and static link checkers verify structure, but only an adversarial audit of the live deployed site at `https://asamarts.github.io/witforge/` proves that real GitHub Pages routing, base-path asset loading, Pagefind search indexing, legacy `.html` fragment redirects, responsive layouts, dark/light contrast, SVG logo rendering, and natural prose quality all hold end-to-end.

## Why it is untestable

Live GitHub Pages HTTP behavior, visual layout polish, cross-viewport rendering, keyboard usability, and editorial tone are verified by live inspection and automated HTTP checks against the deployed URL rather than by `.aplan.yml`'s local Cargo test runners.

## Decision

Default chosen while documenting the task on 2026-11-25, not an owner decision:

- Treat any visual glitch, clipped SVG text, broken base-path asset, broken Pagefind search query, dropped `#wfxxxx` redirect fragment, console error, contrast issue, em dash, or unnatural AI-style phrasing as a blocking defect to fix before closing `M-p12`.
- Include `aplan/tasks/W12-011.md` in `paths:` so that if the live audit finds zero defects and records its complete verification log under `## What was done`, the closure commit passes `aplan verify` cleanly without dummy edits.

## Approach

1. Run live HTTP status and header checks against `https://asamarts.github.io/witforge/`:
   - Canonical routes: `/`, `/outputs/`, `/docs/`, `/docs/quickstart/`, `/docs/diagnostics/`, `/docs/reference/`, `/docs/wiring/`, `/docs/evolution/`, `/docs/ci/`, `/docs/migration/`.
   - Machine-readable and asset endpoints: `/llms.txt`, `/llms-full.txt`, `/robots.txt`, `/favicon.svg`, `/og-card.svg`, `/og-card.png`, `/404.html`, `/pagefind/pagefind.js`.
   - Legacy compatibility URLs: `/guide/`, `/quickstart.html`, `/guide/diagnostics.html`, `/guide/wiring.html`, `/guide/reference.html`, `/guide/ci.html`, `/guide/generated-output.html`, `/guide/json-projections.html`.
2. Verify in a real browser environment (using available `/usr/bin/firefox` headless rendering / browser checks across desktop `1440px` and mobile `375px`):
   - Navigating to `https://asamarts.github.io/witforge/guide/diagnostics.html#wf1015` redirects cleanly to `/witforge/docs/diagnostics/#wf1015` and focuses/scrolls to `WF1015`.
   - Light and dark mode toggle cleanly without FOUC and persist between `/`, `/outputs/`, and `/docs/.../`.
   - Pagefind search returns accurate results for `wire.lock`, `WF1015`, `no_std`, `git-base`, and `witforge-build`.
   - Custom SVG logo renders crisply in the browser tab (`favicon.svg`), navbar, footer, and OpenGraph preview.
   - Zero console errors, zero failed network requests, zero horizontal overflow on mobile, and clean no-JS fallback.
3. Perform a final editorial read of the live homepage, `/outputs/`, `llms.txt`, and key guides confirming zero em dashes, zero AI clichés, and 100% factual alignment with witforge `0.9.0`.
4. Fix any findings discovered, re-deploy, re-verify, and record concrete verification evidence in `## What was done` before closing `W12-011` and `M-p12`.

## Edge cases

- GitHub Pages serves custom `404.html` with HTTP 404 status on unknown paths under `/witforge/`; confirm unknown URLs render witforge's styled 404 recovery page with working base-path CSS and logo.
- Confirm `<meta property="og:image">` resolves to an absolute `https://asamarts.github.io/witforge/og-card.png` returning HTTP 200 with `image/png` on both `BaseLayout` pages and Starlight doc pages.
- Confirm `llms.txt` and `llms-full.txt` return HTTP 200 with clean UTF-8 text and zero em dashes.

## Out of scope

- New witforge compiler features or post-0.9.0 Rust library changes (`M-p10`, `M-p11`).
