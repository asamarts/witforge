## Why

Audit finding F-19 identified post-0.7.0 documentation drift across `AGENTS.md`, `lib.rs`, `overview.md`, `lockfile.md`, `diff.md`, `diagnostics.md`, `dependencies.md`, `action.md`, and `.github/workflows/ci.yml`. All 0.8.0 changes also need coherent `[Unreleased]` entries in `CHANGELOG.md` and a synchronized `docs/design/public-api-inventory.txt`.

## Why it is untestable

Prose consistency, changelog entries, and comment cleanup are verified by doc-link/plan checks (`aplan check-docs`, `ci/check-public-api.sh`, `cargo test --test docs`) rather than a behavioral code test that would fail if prose edits were reverted.

- [ ] All F-19 doc/spec/comment drift items are reconciled
- [ ] `docs/design/public-api-inventory.txt` matches `ci/check-public-api.sh`

- [ ] `aplan check`, `aplan verify`, `aplan check-docs`, and `aplan export-agents-md --check AGENTS.md` pass cleanly
