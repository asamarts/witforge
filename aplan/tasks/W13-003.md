## Why

Plain TypeScript types need deterministic, checked conversions to and from `@bufbuild/protobuf` (`protobuf-es` v2) messages so TypeScript hosts and plugins enforce the exact same 13-row WIT decode profile as Rust glue without hand-written validation.

## Acceptance criteria

- [ ] Implement opt-in TypeScript checked protobuf glue targeting `@bufbuild/protobuf` (`toProto` / `fromProto`, per-function request/response helpers, `METHOD` constants, and structured `WitforgeGlueError`)
- [ ] Enforce all 13 rows of the WIT decode profile including narrow integer bounds (`u8`/`u16`/`s8`/`s16`), Unicode scalar `char`, required `optional` presence, closed enums, exact `list<T, N>` length, `map<K, V>` key validation, and unset `oneof` / wrapper rejection
- [ ] Add golden tests and cross-language binary + proto3-JSON round-trip conformance tests against `W11-034` fixtures generated from Rust glue
