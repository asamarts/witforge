## Why

Consumers need a typed, dependency-free bridge between plain Rust values and
prost values, with every decode rule in one place.

## Acceptance criteria

- [ ] free-function conversions exist for every named type in the highest minor
- [ ] range checks, closed enums, required presence, oneofs, and option wrappers are handled
- [ ] `GlueError` is structured, non-exhaustive, Display, and Error
- [ ] aliases and named structural types delegate or map correctly
- [ ] conversions compile against generated plain/prost types
