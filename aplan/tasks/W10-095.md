## Why

Audit finding D3 (high for 1.0). No model type is `#[non_exhaustive]`, and all have public
fields (`model.rs`). Every addition the roadmap already names (deprecation, source
positions, maps, resources) would be a major version of the library after 1.0. `W10-035`
did this for the diff report types only.

Reviewer-read: `public-api.md` omits public items that exist (`RELEASED_MANIFEST`, eight
root-level helpers, several methods); `emit::output::absolute` has no caller.

## Decision recorded here

Recommendation: before 1.0, make every public struct and enum of the model, lockfile, and
diagnostics `#[non_exhaustive]` with constructors or builders where a consumer must create
one, and make everything the policy table does not list private or `#[doc(hidden)]`.

## Acceptance criteria

- [ ] every public data type is `#[non_exhaustive]` or `public-api.md` says why it is frozen
- [ ] every public item is in the policy table, and a test compares the table with the
      crate's public API listing
- [ ] unused public items are removed
- [ ] the change ships in a minor release before 1.0 with a changelog entry for library
      users
- [ ] the semver gate (`cargo semver-checks check-release -p witforge --release-type minor`)
      rejects this change by design, so the release that carries it lifts `--release-type
      minor` in `ci.yml` and `release.yml` for that release only and restores it afterwards;
      the release checklist names the step
