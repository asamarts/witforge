## Why

Real WIT projects import packages from `wit/deps`; the current subset refuses foreign types
and interfaces, limiting witforge to self-contained contracts.

## Acceptance criteria

- [ ] package identity and foreign type references are modeled explicitly
- [ ] `wit/deps` packages resolve through the standard WIT dependency layout
- [ ] generated Rust/protobuf references distinguish local and dependency packages
- [ ] lockfiles, canonical types, and release freezes define foreign-package behavior
- [ ] tests cover a local package importing a pinned dependency and a missing/ambiguous dependency
- [ ] the design records that multi-package workspaces and registries are separate later work
