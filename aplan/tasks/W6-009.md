## Why

1.0 is a promise about the library API, generated output, and conformance. It
needs a settled surface, cross-platform CI, and a conformance suite, not just
feature completeness.

## Acceptance criteria

- [ ] public API is reviewed and documented
- [ ] typed errors replace boundary `anyhow` where promised
- [ ] conformance fixtures cover every supported WIT construct and mapping
- [ ] CI runs Linux, macOS, and Windows
- [ ] 1.0 release criteria and deprecation runways are published
