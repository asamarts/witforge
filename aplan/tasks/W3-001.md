## Why

The primary deliverable for native consumers is plain Rust types and interface
traits with no runtime dependency.

## Acceptance criteria

- [x] version modules contain per-interface type submodules
- [x] records, variants, enums, flags, options, lists, results, and aliases map as specified
- [x] traits use `&self`, owned values, and no extra bounds
- [x] naming, keyword escaping, derives, docs, and collisions are implemented
- [x] generated code compiles
