## Why

`ConversionImpact` and `DiffAnalysis` are new public structs with all-public fields, so any
future field is a breaking change under the 1.0 policy. `emit::proto::emit_major` has an
invariant `unwrap` on an interface lookup, and public `Model` values can be constructed by
callers. `diff::compare` also computes conversion impacts only to discard them.

## Acceptance criteria

- [ ] `ConversionImpact` and `DiffAnalysis` are marked `#[non_exhaustive]` or explicitly
      documented as fixed, with `public-api.md` updated
- [ ] the proto interface lookup returns a contract/internal error rather than panicking
- [ ] `compare` avoids conversion-impact work when the caller does not request it, or the
      cost is documented and justified
- [ ] semver, the full suite, and `cargo doc` with warnings denied pass
