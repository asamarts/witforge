## Why

`ConversionImpact` and `DiffAnalysis` are new public structs with all-public fields, so any
future field is a breaking change under the 1.0 policy. `emit::proto::emit_major` has an
invariant `unwrap` on an interface lookup, and public `Model` values can be constructed by
callers. `diff::compare` also computes conversion impacts only to discard them.

## Acceptance criteria

- [x] `ConversionImpact` and `DiffAnalysis` are documented as fixed for 1.0, with
      `public-api.md` updated
- [x] the proto interface lookup returns an internal error rather than panicking
- [x] `compare` avoids conversion-impact work when the caller does not request it
- [x] semver, the full suite, and `cargo doc` with warnings denied pass
