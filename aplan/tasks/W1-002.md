## Why

The lockfile records a member's canonical type, and every emitter must agree on
the same spelling. Alias expansion and named structural types are the places a
second implementation would drift.

## Acceptance criteria

- [x] aliases expand recursively
- [x] named list/option/result definitions expand structurally
- [x] named record/variant/enum/flags use `interface/type`
- [x] result slots use `_` and no whitespace
- [x] unit tests cover canonical strings for every primitive and nested shape
