## Why

The lockfile records a member's canonical type, and every emitter must agree on
the same spelling. Alias expansion and named structural types are the places a
second implementation would drift.

## Acceptance criteria

- [ ] aliases expand recursively
- [ ] named list/option/result definitions expand structurally
- [ ] named record/variant/enum/flags use `interface/type`
- [ ] result slots use `_` and no whitespace
- [ ] unit tests cover canonical strings for every primitive and nested shape
