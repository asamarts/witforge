## Why

Audit finding F-16 and Feature #8:
- `json_schema.rs` emits raw `/** *` block-comment gutters and drops `///` docs on record fields, flags, and variant cases.
- Draft 7 ignores `description`/`deprecated` siblings beside `$ref` and is outdated for OpenAPI 3.1 and modern schema tooling.

## Decision

- Normalize WIT docs for JSON Schema descriptions (strip `/** *` gutters, normalize line endings).
- Emit member-level `description` on record fields, flags, and variant cases.
- Add opt-in Draft 2020-12 (`JsonSchemaDraft::{Draft7, Draft202012}`, `json_schema::plan_with_options`, CLI `--draft 7|2020-12`, `[project.<name>.schema] draft = "7" | "2020-12"`, default `7`) emitting `$defs` and `#/$defs/...` and validating against the `jsonschema` Draft 2020-12 validator.

## Acceptance criteria

- [x] JSON Schema descriptions strip `/** *` gutters and preserve clean text
- [x] Record fields, flags, and variant cases carry `description` when documented in WIT
- [x] `--draft 2020-12` and `schema.draft = "2020-12"` emit valid Draft 2020-12 schemas (`$defs`, native `deprecated`, `$ref` siblings) verified by `jsonschema`
- [x] Draft 7 remains the default and committed `examples/` are regenerated and verified
