## Why

Generated output must be reviewable, deterministic, and safe to regenerate. The
layout and ownership rules are part of the API.

## Acceptance criteria

- [x] `mod.rs` and one file per version are written
- [x] LF-only, no timestamps or absolute paths
- [x] stale generated files are removed, unrelated files untouched
- [x] `--check` reports missing, changed, and extra generated files
- [x] generation refuses an output root inside the WIT tree
- [x] the `rust` command is wired to the emitter and output root
