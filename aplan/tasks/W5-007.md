## Why

A second review before the 0.1.0 publish found gaps a consumer would hit: a minor
whose lockfile was started fresh instead of copied could renumber the shared
per-major schema, the generators accepted any `--released` value, `check` reported
every locked member as removed beside a subset violation, contract violations from
`lock` and the generators exited `2`, a non-UTF-8 file in an output root failed
generation, and `..`, `.`, and symlinks could bypass the output-root and
released-directory refusals.

## Acceptance criteria

- [x] the generators require each minor's lockfile to continue the previous minor's,
  and default-mode `lock`/`check` refuse a missing lockfile
- [x] every command validates the released manifest it uses
- [x] `check` reports only subset violations when there are any
- [x] every contract, lockfile, or output violation exits `1`; usage, I/O, and parse
  errors exit `2`
- [x] output roots ignore files that are not UTF-8 text
- [x] the output-root and released-directory refusals compare resolved paths
- [x] released-manifest entries are plain directory names, as the freeze script requires
