## Why

Audit findings F-08, F-09, F-15, and F-18:
1. `rust.rs`'s `resolves_to_unit_err_result` and `estimate_type_size` lose `Dependency` scope on foreign alias chains/records, causing default `cargo clippy -- -D warnings` failures (`result_unit_err`, `large_enum_variant`).
2. Deeply nested `option`/`result`/`list` types fail `clippy::type_complexity` in plain Rust and glue, and fail `rustfmt --edition 2024 --check` in glue due to unwrapped deeply-indented `Clone::clone(...)` and `return Err(...)` lines.
3. Named `option<result<...>>` leaks `@deprecated`/`@since` onto the shared anonymous `WitforgeResult...` proto wrapper; docs on named `option<list/option>` wrappers are dropped; stability comments on wrappers lack a preceding blank line.
4. Unreferenced local aliases/lists pointing to dependency types emit unused `.proto` `import` statements (`protoc` warning).
5. A live proto field can collide on proto3 `json_name` with a `reserved` field name (`foo_1` vs `foo1`).

## Decision

- Thread `Option<&Dependency>` through `resolves_to_unit_err_result` and `estimate_type_size`.
- Emit `#[allow(clippy::type_complexity)]` where generated types/signatures cross Clippy's complexity threshold and fix 100-column `rustfmt` wrapping in `glue.rs`/`rustfmt.rs`.
- Attach stability/docs only to dedicated named option wrappers (never shared `Witforge*` wrappers) and emit docs + blank line cleanly.
- Track proto `used_imports` only for emitted declarations/wrappers, eliminating unused imports on unreferenced local aliases.
- Check proto3 `json_name` collisions against reserved field names in `proto.rs`/`subset.rs`.

## Acceptance criteria

- [ ] Compile-matrix / clippy tests pass `-D warnings` and `rustfmt --check` on dependency alias `result_unit_err`, dependency `large_enum_variant`, and deeply nested `type_complexity` shapes
- [ ] Named `option<result<...>>` does not leak `@deprecated`/`@since` onto shared anonymous wrappers, and named `option<list/option>` wrappers carry WIT docs
- [ ] Unreferenced local foreign aliases emit no unused `.proto` `import`
- [ ] Proto3 `json_name` collisions with reserved field names are refused by `check` and `proto`
