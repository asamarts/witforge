## Why

The lockfile knows wire continuity, but users need a focused report of what changed between
two contract versions and whether it is wire-, source-, or generated-API breaking.

## Acceptance criteria

- [ ] `witforge diff <old> <new>` compares two version directories or roots
- [ ] human and JSON output classify added, removed, reordered, retyped, and defaulted changes
- [ ] `--check` exits non-zero on breaking changes and tests cover every category
- [ ] the output distinguishes wire identity from generated API compatibility
