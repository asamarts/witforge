## Why

The lockfile knows wire continuity, but users need a focused report of what changed between
two contract versions and whether it is wire-, source-, or generated-API breaking.

## Acceptance criteria

- [x] `witforge diff <old> <new>` compares two version directories or roots
- [x] human and JSON output classify added, removed, reordered, retyped, and defaulted changes
- [x] `--check` exits non-zero on breaking changes and tests cover every category
- [x] the output distinguishes wire identity from generated API compatibility
