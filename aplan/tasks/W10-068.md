## Why

Audit finding D5 (high). Every "generated code does not compile" finding of this audit
(`W10-059` to `W10-066`) passed the existing suite, because:

- golden files are produced by the emitter they test, so they prove stability, not
  correctness;
- only a handful of fixtures are compiled against prost (`emit_glue.rs`, `deps_glue*.rs`,
  `serde.rs`, `e2e.rs`), all with lower-case multi-letter names;
- the examples' generated code is checked for drift but never compiled (the roadmap lists it
  as planned);
- no test states the invariant "`check` passes ⇒ generators succeed ⇒ output compiles".

## Acceptance criteria

- [ ] one compile-and-round-trip harness takes a WIT directory and builds plain Rust, glue,
      and prost output in a scratch crate; the scratch directory honours `TMPDIR`
- [ ] a name matrix (one-letter words, upper-case words, digits, every Rust and proto
      keyword) and a shape matrix (each kind in each position, three levels of nesting,
      dependency-declared types) run through it
- [ ] the property generator's contracts run through the harness for a bounded sample
- [ ] `examples/*` generated code is compiled and its round trip run in CI
- [ ] generated output is also built with `-D warnings`, `cargo doc -D warnings`, and
      `cargo fmt --check` or the documented attributes (see `W10-074`)
- [ ] `quality.md` and `conformance.md` describe the harness
