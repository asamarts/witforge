## Why

Audit findings F-03, F-06, F-07, F-10, and F-18:
1. `lock::CanonicalTypeParser` checks `depth >= 32` before parsing leaf types, rejecting 32-level nested types that `model` and `witforge lock` accept (`WF9003`, exit 2).
2. `SinceHistory` records `@unstable` items as `first_seen` and never resets after removal, falsely rejecting `@unstable` -> `@since` stabilization and re-adding removed names in a new major.
3. `@since` and `@deprecated` silently drop semver pre-release and build metadata instead of refusing them with `WF1014`.
4. `load_sources` resolves parse/resolution spans from disk instead of in-memory source buffers, losing positions or reading unrelated files in cwd.
5. `subset.rs` swallows non-`ContractError` errors and strips diagnostic codes/locations from `proto::validate_model`; `sibling_predecessor` does not check `wire.lock` existence; `tests/bench.rs` debug budget flakes at 250ms under host load.

## Decision

- Count nesting only on `list`/`option`/`result` in `CanonicalTypeParser`.
- Track contiguous non-unstable lifetime in `SinceHistory` (skip `@unstable`, reset `first_seen` when absent from an intermediate version).
- Reject pre-release/build metadata on `@since`/`@deprecated` with `WF1014`.
- Pass virtual source map into `resolve_span_location` in `load_sources`.
- Preserve diagnostic codes/locations in `subset.rs`, align `sibling_predecessor` doc/behavior, and relax `tests/bench.rs` debug ceiling while keeping release ceilings strict.

## Acceptance criteria

- [ ] 32-level nested type locks and parses cleanly; 33 levels fails consistently
- [ ] `@unstable` -> `@since` stabilization and removal + cross-major re-addition pass `SinceHistory`, while bogus `@since` on unbroken items still fails
- [ ] `@since`/`@deprecated` with pre-release or build metadata fail with `WF1014`
- [ ] `load_sources` parse/resolution errors carry exact virtual file/line/column even when absent from disk or shadowed by a disk file
- [ ] `subset.rs`, `sibling_predecessor`, and `tests/bench.rs` issues are resolved with regression tests
