wire surface of the plugin protocol.

- [x] responses always carry `result = 1` and `METHOD` values are locked
- [x] required presence and oneof singularization are correct
- [x] removed members emit reserved numbers and names
- [x] unknown/zero enum values are represented as decode errors in glue, not schema defaults
