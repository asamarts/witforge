## Why

Function request/response messages, method-id enums, and reserved members are the
wire surface of the plugin protocol.

## Acceptance criteria

- [ ] request messages number parameters from the lockfile
- [ ] responses always carry `result = 1` and `METHOD` values are locked
- [ ] required presence and oneof singularization are correct
- [ ] removed members emit reserved numbers and names
- [ ] unknown/zero enum values are represented as decode errors in glue, not schema defaults
