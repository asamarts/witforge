## Why

The proto emitter needs the same command, output-root, ownership, and stale-output behavior as the Rust and glue emitters. Validation alone does not produce a usable `.proto` file.

## Acceptance criteria

- [ ] `proto <wit-root> --out <dir>` is wired through the CLI
- [ ] one file per major is written from the highest minor
- [ ] the output root is created, and an output root inside the WIT tree is refused
- [ ] stale generated proto files are removed; unrelated files are untouched
- [ ] `--check` reports missing, changed, and extra generated files
- [ ] output is deterministic and LF-only
