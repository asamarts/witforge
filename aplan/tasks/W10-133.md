## Why

Ninth-wave independent dual-agent adversarial audit of `v0.8.0..33b3a72` uncovered 23 concrete
defects across the core compiler, CLI, GitHub Action, CI scripts, and documentation:

- **Core compiler & emitters (10):**
  1. `emit/convert.rs`: `emit_try_from_impl` calls unqualified `{function}(value)` which is
     shadowed by parameter `value` for any nominal WIT type named `value` (`E0618`).
  2. `diff.rs`: `inspect_git_sibling_released` silently ignored directory (`040000`) and
     submodule (`160000`) `released` entries and swallowed `ls-tree` errors;
     `validate_git_released_directory` misclassified submodule entries as `WF9002` instead of
     `WF9004`.
  3. `diff.rs`: `compare_git_base` did not refuse working-tree git submodules (`.git` inside
     target or `160000` gitlinks).
  4. `emit/rust.rs`: `write_derives` at `indent >= 12` (per-major scoped deps) with both
     `--serde` and `--eq-hash` emitted a 98-col line that `rustfmt` 2021 & 2024 both wrap.
  5. `emit/rustfmt.rs`: fixed-length array types `[Elem; N]` diverged from `rustfmt` at
     boundary widths in `fmt_type`, `fmt_struct_field`, and `fmt_type_alias`.
  6. `emit/doc.rs`: `index.md` `Version Changes` `Detail` cells emitted unescaped `<...>`
     type expressions without backticks (parsed/stripped as raw HTML in CommonMark/GFM).
  7. `emit/doc.rs`: `write_normalized_docs` and `inline_doc_cell` wrote raw WIT docs without
     closing unclosed fences, escaping raw HTML/comments, or balancing table-cell backticks.
  8. `diff.rs`: `redact_git_base_string` missed `shell_quote`-escaped single quotes (`'\''`).
  9. `emit/rust.rs` & `diff.rs`: `resolves_to_option` and `is_absent_ok_in`/`resolves_to_u8_in`
     used a flat depth cap instead of visited-set cycle guards for legal >32-hop cross-package
     alias chains.
  10. `emit/convert.rs` & `emit/glue.rs`: deeply nested `FixedLengthList` `let_else_head` /
      `try_from` and deeply nested `Map` `.push`/`.insert` diverged from `rustfmt`.
- **CLI, Action, CI & Docs (13):**
  11. `witforge-cli/src/main.rs`: discovered `[project.<name>.policy]` was bypassed when
      `project.root` used `../` or was a symlink outside `witforge.toml`'s directory.
  12. `action/index.js` & `action.yml`: `generators: doc` was rejected.
  13. `completions.rs`: Fish `witforge help <TAB>` emitted contradictory `A && !A` condition.
  14. `completions.rs`: Bash completion broke after `--format=<value>` (`COMP_WORDBREAKS` `=`).
  15. `completions.rs`: Zsh completion had unescaped `NS:NAME`, mandatory `:` on `--check=-`,
      and missing `_files -/` on `init DIR`.
  16. `completions.rs`: Fish emitted `-r` on `diff --check` despite `require_equals = true`.
  17. `main.rs`: `shell_quote` corrupted `--project` names starting with `-` in fix-it hints.
  18. `workflow.rs`: `replace_deps_dir_atomic` used `create_dir_all` on predictable staging
      names and silently discarded backup cleanup errors.
  19. `main.rs`: `--draft` lacked clap `value_parser = ["7", "2020-12"]` for completions.
  20. Factual contradictions in `docs/guide/choosing-witforge.md`, `docs/quickstart.md`,
      `docs/design/overview.md`, and `ROADMAP.md` still stating `char`/`list<T, N>`/`map<K, V>`
      are refused or `Eq`/`Hash` declined.
  21. Stale normative spec in `docs/design/diff.md` for sibling `released` and `[<path>]`.
  22. Incomplete `0.9.0` tables in `docs/design/public-api.md` and `docs/design/conformance.md`.
  23. Missing `0.9.0` guide/CI coverage (`wiring.md`, `diagnostics.md`, `generation.md`,
      `json-projections.md`, `ci.md`, `emitters.md`, `evolution.md`, `contract-authoring.md`,
      `README.md`, `docs/index.md`, `ci/check-generated.sh`, `ci/release-checklist.md`).
