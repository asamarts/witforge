## Why

Users need a path from installation to a generated Rust/protobuf/schema project, and a clear
statement of what witforge is not (a runtime or transport).

## Acceptance criteria

- [ ] a quickstart covers install, lock, check, all emitters, and `witforge.toml`
- [ ] examples cover a single version and an evolved two-version contract
- [ ] the guide explains the WIT subset and the protobuf-first non-Rust strategy

workspace tests where they become code.
