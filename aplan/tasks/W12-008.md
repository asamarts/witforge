## Why

A static documentation and promotional site can silently regress through broken internal links, missing `#fragment` anchors, broken `HELP_BASE_URL` redirects, unindexed Pagefind builds, malformed SVG diagrams, drifted code examples, or reintroduced em dashes and AI-style clichés. Running a deterministic post-build verification script (`site/scripts/check-links.mjs`) locally and in CI prevents every one of those defects from ever reaching GitHub Pages.

## Why it is untestable

This task implements a Node post-build audit script inspecting `site/dist/` rather than Rust crate code tested by `.aplan.yml`'s Cargo runners. Its pure helper logic is tested by `node --test site/scripts/test-scripts.mjs` (which `W12-009` also bridges into `cargo test`), and the full check runs via `npm --prefix site run check:links` and `.github/workflows/docs.yml` in `W12-010`.

## Decision

Default chosen while documenting the task on 2026-11-25, not an owner decision:

- Model `site/scripts/check-links.mjs` on the proven link, fragment, SVG, and em-dash gates in `asamarts/ayaml`, extended with witforge-specific invariants:
  1. **Internal links & trailing slashes**: every internal `href` and `src` across all built HTML files resolves to a file in `site/dist/`, and canonical page routes use trailing slashes. Exempt redirect stubs dynamically by loading `site/scripts/redirects.json` (covering both `/quickstart.html` and `/guide/*.html`).
  2. **Fragment anchors & `WFxxxx` diagnostic IDs**: every `#fragment` link resolves to an element `id` on its target HTML page, and `dist/docs/diagnostics/index.html` contains lowercase `id="wfxxxx"` matching every `### WFxxxx` heading in `docs/guide/diagnostics.md`.
  3. **Legacy redirect stubs**: every entry in `site/scripts/redirects.json` exists in `site/dist/`, targets a real built page, preserves `window.location.search + window.location.hash`, and includes an absolute canonical link.
  4. **GitHub repo links**: every `https://github.com/asamarts/witforge/blob|tree/main/...` URL in built HTML resolves to an existing path in the repository.
  5. **Required site artifacts**: verify `dist/robots.txt`, `dist/404.html`, `dist/favicon.svg`, `dist/og-card.svg`, `dist/og-card.png`, `dist/llms.txt`, `dist/llms-full.txt`, and `dist/pagefind/` exist and are non-empty (plus `dist/sitemap-index.xml` if referenced by `robots.txt`).
  6. **SVG diagram hygiene**: every inline SVG diagram carries `role="img"`, `aria-labelledby`, `<title>`, `<desc>`, and a valid numeric `viewBox` with no elements placed outside the viewBox bounds.
  7. **Zero em dashes and AI-prose cliché guard**: scan all rendered HTML prose (excluding `<code>`, `<pre>`, `<script>`, and `<style>` blocks) plus `llms.txt` and `llms-full.txt` and fail on any `U+2014`, `&mdash;`, `&#8212;`, `&#x2014;`, or banned marketing clichés (such as `delve`, `seamlessly`, `supercharge`, `cutting-edge`, `game-changer`, `unlock the power`, `empower your`).
  8. **Version & example sync**: assert rendered pages reflect the live workspace version from `Cargo.toml` and that landing-page code tour excerpts exist verbatim inside `examples/single/` and `examples/evolved/`.

## Approach

1. Implement `site/scripts/check-links.mjs` using only cross-platform Node 20+ standard library modules (normalizing `\` -> `/` paths and using `process.env.TMPDIR || os.tmpdir()` in tests).
2. Add `check:links` and a combined `verify` script (`test:scripts && build && check:links`) to `site/package.json`.
3. Add unit tests in `site/scripts/test-scripts.mjs` exercising negative cases (broken href, missing `#fragment`, em dash in HTML prose, em dash in `llms.txt`, banned cliché phrase, SVG missing `<title>`, invalid `viewBox`) so the gate itself is proved to catch regressions.
4. Run `npm --prefix site run verify` end-to-end and resolve any finding surfaced across `W12-001` through `W12-007`.

## Edge cases

- Code blocks (`<pre>`, `<code>`), `<script>`, and `<style>` blocks must be stripped before HTML prose cliché/em-dash scanning while still scanning headings, paragraphs, list items, table cells, `<title>`, `<meta name="description">`, and SVG `<text>`/`<title>`/`<desc>`.
- Redirect stubs listed in `site/scripts/redirects.json` (including both `dist/quickstart.html` and `dist/guide/*.html`) intentionally use `.html` filenames and must be validated by the redirect checker rather than rejected by the canonical trailing-slash check.
- External URLs (such as `docs.rs` or `crates.io`) must not trigger flaky network calls during offline CI builds; verify repository `github.com/asamarts/witforge/blob|tree/main/...` links locally against the git working tree.

## What was done

- Implemented `site/scripts/check-links.mjs` using Node stdlib only to enforce all eight verification gates against `site/dist/`:
  1. Internal `href`/`src` resolution and canonical trailing-slash checks (including `llms.txt` / `llms-full.txt` site URLs, dynamically loading `site/scripts/redirects.json` to exempt legacy `.html` stubs and forbid canonical pages from linking to stubs).
  2. Fragment anchor verification across all internal links plus 1-to-1 verification that every `### WFxxxx` code in `docs/guide/diagnostics.md` has a matching lowercase `id="wfxxxx"` anchor in `dist/docs/diagnostics/index.html`.
  3. Full validation of all 16 legacy redirect stubs (stub header, `noindex`, absolute `canonical`, `window.location.search + window.location.hash` preservation, `<noscript>` refresh, fallback link, and exclusion from `sitemap-0.xml`).
  4. Offline verification of every `https://github.com/asamarts/witforge/(blob|tree|edit)/main/...` link in built HTML and `llms*.txt` against the local repository tree.
  5. Verification of required site artifacts (`robots.txt`, `sitemap-index.xml` and referenced sitemap chunks, `404.html`, `favicon.svg`, `og-card.svg`, PNG-header-verified `og-card.png`, `llms.txt`, `llms-full.txt`, and Pagefind index/fragments).
  6. Inline SVG diagram checks (`role="img"`, valid `aria-labelledby` references, non-empty `<title>` and `<desc>`, numeric `viewBox`, and coordinate bounds checks across `<rect>`, `<circle>`, `<ellipse>`, `<line>`, `<text>`, and `<path>`).
  7. Zero em dashes, zero stray en dashes, zero leaked Markdown table backticks, and zero banned AI clichés across rendered HTML prose (excluding `<pre>`, `<code>`, `<script>`, `<style>`) and `llms*.txt`.
  8. Live `Cargo.toml` workspace version sync across `index.html` and `llms*.txt`, plus verbatim line-for-line verification of all 7 landing-page Output Tour code panels against `examples/single/` and `examples/evolved/`.
- Added `check:links` and `verify` (`test:scripts && check && build && check:links`) scripts to `site/package.json`.
- Added 3 positive/negative test suites (19 total passing tests) in `site/scripts/test-scripts.mjs` and verified `npm --prefix site run verify` passes cleanly across 19 canonical pages, 16 redirects, 1,300+ internal links, 53 `WFxxxx` anchors, 111+ GitHub links, 2 inline SVG diagrams, and 7 Output Tour excerpts.
