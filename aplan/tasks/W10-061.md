## Why

Audit findings B3 and B4 (high). A dependency that declares a structural alias produces glue
that does not compile, although every generator exits 0.

Re-run 2026-11-18 against prost 0.14, with a passing control (dependency record and
`list<u16>` alias) in the same scratch crate:

```wit
// deps/shared: package ex:shared@0.1.0;
interface types { type nested = list<list<u16>>; }
// root: record holder { a: nested }
//   → E0425/E0422: cannot find `WitforgeListOfU16` in `crate::proto::ex::shared::v0`

// deps/shared: interface types { type blob = list<u8>; }
// root: record holder { a: blob, b: list<blob>, c: option<blob> }
//   → E0609: no field `values` on type `Vec<u8>`; "comparison operators cannot be chained"
```

The root's proto file defines the wrapper while the dependency's glue expects it in the
dependency's proto package (`proto.rs:845-862`, `1031-1083`; `glue.rs:2133-2137`,
`2310-2313`, `453-458`), and the dependency paths have no byte-list case
(`glue.rs:2204-2211`, `2375-2381`). Reviewer-run: root and dependency project one type to
different wrappers (eight E0308 errors).

## Approach

Default chosen while documenting the task on 2026-11-19, not an owner decision.
A wrapper belongs to the package whose source writes the shape. A shape
reached through a dependency's named type uses the wrapper in the dependency's
proto package. A shape written in the root uses a wrapper in the root's package,
also when its element type is foreign. A dependency's proto file is then a
function of the dependency alone (see `W10-060`), and both glue trees refer to a
wrapper where it is defined.

## Edge cases

- One anonymous shape needed by the root and by a dependency (`list<list<u16>>` in
  both): two wrappers in two packages, two Rust types. This is the reviewer's
  eight `E0308` errors.
- A dependency byte-list alias as a record field, a list element, an option
  payload, a result side, a variant payload, a parameter, and a function result.
  After `W10-046` the alias may itself be spelled through an alias of `u8`.
- A dependency alias of an alias, and a named structural type declared in a
  dependency of a dependency.
- A dependency's structural alias that nothing refers to (`W10-060`).
- A root's anonymous shape whose element is a dependency type:
  `list<list<dep-item>>`.
- The import lines and qualified names that the moved wrappers need (`W10-062`).
- Two roots that share a dependency generate byte-identical files for it.
- The control of the reproduction, a dependency record and a `list<u16>` alias,
  keeps compiling.

## Acceptance criteria

- [ ] a wrapper needed by a dependency type is defined in exactly one proto package and both
      glue trees refer to it there
- [ ] dependency byte-list aliases work as a field, a list element, and an option payload
- [ ] the dependency compile tests cover nested lists, options of lists, results, and byte
      lists declared in the dependency and used by the root
