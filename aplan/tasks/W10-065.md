## Why

Audit findings B8 and B10 (medium).

- Re-run 2026-11-18: a dependency declaring `record get-request` and `get: func()` makes
  `witforge proto` exit 1 ("proto name `TypesGetRequest` is produced by both …") and
  `witforge glue` exit 0 (`glue.rs:120-131`). Glue is generated for a schema that cannot
  exist.
- Reviewer-run: for a foreign named option in a list or oneof position, `from_proto` accepts
  an unset wrapper as `None` (`glue.rs:2389-2392`); the local and anonymous paths return
  `InvalidState` for the same input.
- Reviewer-run: synthesized glue helpers have no doc comment although `emitters.md`
  section 7.1 says each gets one, and empty doc lines carry trailing whitespace.

## Acceptance criteria

- [ ] glue runs the proto emitter's validation for the root and every dependency
- [ ] an unset wrapper is `InvalidState` on every path, with a test per path
- [ ] generated helpers are documented as the specification says and no generated line ends
      in whitespace
