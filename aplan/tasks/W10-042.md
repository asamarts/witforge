## Why

Audit findings F1 (high) and F2 (medium).

- The first WIT example in `docs/quickstart.md:52-62` declares `interface greeter` and
  `world greeter`. WIT keeps interfaces and worlds in one namespace, so
  `witforge lock … --first` exits 2 with ``duplicate item named `greeter` `` and every later
  quickstart command fails. Re-run 2026-11-18.
- The "evolve a contract" sequences in `README.md`, `docs/quickstart.md`, and
  `docs/guide/evolution.md` start with `cp wit/v0.1/wire.lock wit/v0.2/wire.lock`. The
  quickstart shows the target tree but no page says to create `wit/v0.2`, copy the WIT, and
  change the package version to `@0.2.0`. Skipping the version change gives
  `declares package version 0.1.0, expected 0.2.0`.
- `docs/guide/evolution.md:24` says conversion can default "flags"; only an added flag
  *member* defaults, an added field of a flags type is refused. The same line says new-to-old
  conversion "reports data that cannot be represented", but added fields are dropped
  silently (emitters.md section 9.3).
- `examples/README.md:31-33` says to add `v0.3` although `v0.2` is an unreleased draft.
- The snippet check in `crates/witforge-cli/tests/distribution.rs` covers only
  `generated-output.md` and the README excerpts, so `ROADMAP.md`'s "documentation snippets …
  are checked in CI" overclaims.

## Acceptance criteria

- [x] the quickstart's first example locks, checks, and generates when copied verbatim
- [x] every evolution sequence includes the directory, WIT copy, and version-bump steps
- [x] a test extracts the quickstart and evolution command blocks and runs them against the
      built binary
- [x] the evolution guide's statements about flags and new-to-old conversion match
      emitters.md section 9
- [x] the roadmap claim about checked snippets is true or reworded

## Verification

`crates/witforge-cli/tests/docs.rs` walks `README.md`, `docs/quickstart.md`, and
`docs/guide/evolution.md` in order, saves their `wit` and `toml` blocks where the text says, and
runs every `sh` block through a small interpreter against the built binary. The three document
tests fail on the previous text of each document. The roadmap now claims only what is checked;
the command-sequence tests are recorded in the changelog.
