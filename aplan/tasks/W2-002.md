## Why

Type and kind changes are invisible to protobuf when the wire type is unchanged.
The lockfile must record both from the model.

## Acceptance criteria

- [x] every type member records its kind and type
- [x] method ids record the result type or no type
- [x] parameters record their type
- [x] reserved entries retain kind and type
- [x] a type or kind change is detected
