## Why

Type and kind changes are invisible to protobuf when the wire type is unchanged.
The lockfile must record both from the model.

## Acceptance criteria

- [ ] every type member records its kind and type
- [ ] method ids record the result type or no type
- [ ] parameters record their type
- [ ] reserved entries retain kind and type
- [ ] a type or kind change is detected
