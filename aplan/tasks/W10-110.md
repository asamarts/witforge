## Why

Non-Rust tooling, documentation generators, contract linters, and third-party emitters currently have to embed the Rust `witforge` crate or re-parse WIT and `wire.lock`. A stable, versioned JSON IR on stdout unlocks external emitters immediately and de-risks `W11-001`.

## Decision

- Add `witforge::inspect` (pure library JSON renderer with zero new dependencies, deterministic key/item ordering, `version: 1`) and CLI `witforge inspect [<PATH>] [--json] [--config/--no-config/--project] [--released <PATH>]`.
- Support both a single version directory and a WIT root (emitting every live version, resolved dependencies, canonical types, stability, docs, wire numbers, reserved entries, and order fingerprints).

## Acceptance criteria

- [x] `witforge inspect --json` emits deterministic, schema-versioned (`version: 1`) JSON IR for single versions and multi-version roots with `deps/`
- [x] Human summary mode prints a concise version/interface/member/lockfile overview
- [x] Library and CLI tests verify deterministic JSON round-trip and all WIT constructs
