## Why

Audit findings B6 and B10 (medium), all exit 0 from `witforge` and a build failure for the
consumer.

- Re-run in the first audit pass: a field, flag, or parameter named `extern` is `r#extern`
  in glue and `extern_` in prost's output (E0560). `rust_ident` in `emit/mod.rs` appends `_`
  only for `crate`, `self`, `super`, `Self`.
- Re-run 2026-11-18: `record cfg { mode: mode, set-mode: bool }` with `enum mode` makes prost
  generate the enum accessor `set_mode` and a field named `set_mode`
  (E0592 duplicate definitions).
- Reviewer-run: a dependency package segment that is a Rust keyword (`example:gen`) is not
  escaped in module paths (`glue.rs:300-306`, `418-424`).

## Decision

Default chosen while documenting the task on 2026-11-19, not an owner decision.
An accessor collision is refused by `check`. Generating around it would
need another proto field name, and the field name is the WIT name.

## Edge cases

- The escaping table is read from the prost-build release under test, not written
  from memory. It has two classes: keywords that become raw identifiers, and the
  few that cannot be raw and get a trailing underscore (`extern` is in the second
  class, as the reproduction shows). Edition 2024's `gen` is in it.
- Plain Rust has its own escaping. Glue converts between a plain field and a prost
  field whose escaped forms differ.
- A trailing underscore cannot collide with another WIT name, because WIT
  identifiers have no underscore. Say so next to the table.
- Which accessors prost generates depends on the field: a getter for an optional
  scalar, a getter and a setter for an enum, and more for a repeated enum. The
  collision rule is derived from what the prost-build release under test emits,
  and the test compiles each case. A hand-written list goes stale; the names
  `clear-x` and `x-or-default` in the criterion are examples to check, not facts
  about prost.
- Collisions across message kinds: a record's fields, a flags type's members, and
  the parameters of a function in its request message.
- A dependency package or namespace segment that is a Rust keyword (`example:gen`,
  `example:type`), and the segments that cannot be raw identifiers.
- The refusal is reported by `check` (`W10-067`), names both fields, and says
  which generated accessor they share.

## Acceptance criteria

- [ ] field and module identifiers in glue come from the same escaping table prost-build
      uses, with a test that enumerates every Rust keyword as a field name
- [ ] a message whose field would collide with an accessor prost generates for another
      field (the reproduction's `mode` beside `set-mode`) is refused by `check`, and the
      rule is derived from the prost-build release under test
- [ ] dependency module paths escape keywords
